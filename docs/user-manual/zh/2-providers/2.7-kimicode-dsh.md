# 2.7 Kimi Code CLI 与 DeepSeek Harness

本分支新增对两个工具的一等支持，二者均采用**切换模式**：选中一个供应商，它即成为该工具的默认模型。

## Kimi Code CLI（`kimicode`）

月之暗面的终端编程智能体——命令为 `kimi`（npm `@moonshot-ai/kimi-code`）。

### 配置目录

默认：`~/.kimi-code/`（可用环境变量 `KIMI_CODE_HOME` 重定位）。

### 关键文件

```
~/.kimi-code/
├── config.toml       # 供应商、模型、default_model、thinking、MCP 超时
├── mcp.json          # 用户级 MCP 服务器（mcpServers）
├── AGENTS.md         # 系统提示词 / 指令
├── skills/           # Skills 目录
└── sessions/         # 会话记录
```

### config.toml

CC Switch 把所选供应商写入 `[providers.<key>]`，声明对应的 `[models."<alias>"]`，并设置顶层 `default_model`。写入是**非破坏式**的：`[thinking]`、`[loop_control]` 等无关表，以及 `/login` 托管的（OAuth）供应商都会被保留。

```toml
default_model = "kimi-code/kimi-for-coding"

[providers.moonshot]
type = "kimi"
base_url = "https://api.moonshot.ai/v1"
api_key = "sk-xxx"

[models."kimi-code/kimi-for-coding"]
provider = "moonshot"
model = "kimi-for-coding"
max_context_size = 262144
```

| 字段 | 说明 |
|-------|-------------|
| `providers.<key>.type` | `kimi`、`anthropic`、`openai` 或 `openai_responses` |
| `providers.<key>.base_url` | API 地址 |
| `providers.<key>.api_key` | API Key（凭据仅从此文件读取） |
| `default_model` | 当前模型别名 |

### MCP

MCP 服务器同步到 `~/.kimi-code/mcp.json` 的 `mcpServers` 下，与 Claude 的 MCP JSON 形状一致。

### Skills / 提示词 / 会话

- Skills：`~/.kimi-code/skills/`
- 提示词：`~/.kimi-code/AGENTS.md`
- 会话：`~/.kimi-code/sessions/`（可在会话管理器中浏览；用 `kimi --session <id>` 恢复）

## DeepSeek Harness（`dsh`）

DeepSeek 的插件化智能体框架——命令为 `dsh`（npm `@deepseek-ai/dsh`）。

### 配置目录

默认：`~/.dsh/`（可用环境变量 `DSH_HOME` 重定位）。

### 关键文件

```
~/.dsh/
├── settings.yaml       # 供应商路由 + agent-default-model
├── .credentials.yaml   # 凭据存储（refs.<ENV_NAME>）
├── AGENTS.md           # 用户全局指令
├── skills/             # Skills 目录
└── sessions/           # 会话日志
```

### settings.yaml

CC Switch 把所选路由写入 `llm-pi-ai.providers.<id>`，并让 `agent-default-model` 指向它。其他命名空间（如 `web-search-deepseek`）会被保留。

```yaml
llm-pi-ai:
  providers:
    moonshotai:
      displayName: Moonshot AI (Kimi)
      api: openai-completions
      baseURL: https://api.moonshot.ai/v1
      apiKeyEnv: MOONSHOT_API_KEY
      models:
        - id: kimi-k2
          name: Kimi K2
          contextWindow: 262144

agent-default-model:
  provider: moonshotai
  model: kimi-k2
```

| 字段 | 说明 |
|-------|-------------|
| `llm-pi-ai.providers.<id>.api` | `openai-completions`、`openai-responses` 或 `anthropic-messages` |
| `llm-pi-ai.providers.<id>.baseURL` | API 地址（使用内置目录 id 时可省略） |
| `llm-pi-ai.providers.<id>.apiKeyEnv` | 凭据引用名 |
| `agent-default-model` | 当前路由（`provider` + `model`） |

### 凭据

API Key 本体写入 `~/.dsh/.credentials.yaml` 的 `refs` 下，键名为 `settings.yaml` 中使用的 `apiKeyEnv`：

```yaml
version: 1
refs:
  MOONSHOT_API_KEY: sk-xxx
```

### MCP

暂缓。DSH 通过不稳定的 Cordis patch 格式（`cordis.patch.yml`）配置 MCP；应用已注册，但暂不投影 MCP 服务器。

### Skills / 提示词 / 会话

- Skills：`~/.dsh/skills/`
- 提示词：`~/.dsh/AGENTS.md`
- 会话：`~/.dsh/sessions/`（JSONL，自动识别 zstd；可在会话管理器中浏览）

## 说明

- 两个工具共享统一的**供应商 / MCP / Skills / 提示词 / 会话**面板；可在**设置 → 主界面显示**中启用或隐藏。
- 切回工具自带官方登录需在工具内部完成（Kimi 为 `/login`）；CC Switch 只改写它负责管理的供应商路由。
